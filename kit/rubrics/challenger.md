# Challenger rubric (open points)

Input: the SPEC's open points with their options and recommendations, before any of them goes to the user. For each point:

- CH-1 Argue the strongest case for an option that was not recommended.
- CH-2 Name an option the author did not list, if one exists.
- CH-3 Name the cost or risk of the recommended option that the SPEC does not state.
- CH-4 Say whether you would keep the recommendation, and why, in two sentences.

One block per point: the point's id, then CH-1 to CH-4 on a line each, `none` where you have nothing. End with the points where you would change the recommendation and the new options, one line each; the controller puts those options beside the author's.
